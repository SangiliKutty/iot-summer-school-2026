# LED Blink Project

## Project Title
Arduino LED Blink Project

## Hardware Required
- Arduino UNO
- LED
- 220Ω Resistor
- Breadboard
- USB Cable
- Jumper Wires
- Potentiometer (for speed control)

## Circuit Diagram Description
Connect the LED anode (+) to Digital Pin 13 through a 220Ω resistor.
Connect the LED cathode (-) to GND.
Connect the potentiometer middle pin to A0, and the other two pins to 5V and GND.

## How to Upload the Code
1. Open Arduino IDE.
2. Open the led_blink.ino file.
3. Select Board: Arduino Uno.
4. Select the correct COM Port.
5. Click Verify (✔).
6. Click Upload (→).

## Expected Output
The LED blinks continuously.
The blink count is displayed on the Serial Monitor.
The potentiometer changes the blink speed.

## Troubleshooting Tips
1. Check the USB cable connection.
2. Verify the correct COM Port is selected.
3. Ensure the LED polarity is correct.
4. Make sure the Arduino Uno board is selected.
